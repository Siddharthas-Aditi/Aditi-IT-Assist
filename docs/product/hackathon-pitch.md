# Hackathon Pitch — Aditi IT Assist

## 🎯 One-Liner

**AI-powered IT support that resolves 60%+ of common issues instantly — no waiting,
no tickets, no frustration.**

## 🔥 The Problem (30 seconds)

Every day, Aditi employees lose productive hours waiting for IT support on issues
that have known solutions. Outlook not syncing? Intune compliance? Zoom audio?
These are solved problems — but the solutions are locked in documentation nobody reads.

## 💡 The Solution (60 seconds)

**Aditi IT Assist** is an intelligent support agent that:
- Understands your issue in plain English
- Knows every troubleshooting playbook
- Guides you step-by-step to resolution
- Escalates to humans only when truly needed — with full context

It's not a chatbot. It's a **multi-agent AI workflow** that thinks like your best
IT support engineer.

## 🏗️ Architecture (30 seconds)

- **6 specialized AI agents** working together via LangGraph
- **Knowledge-grounded** responses (no hallucination)
- **Confidence scoring** — it knows when to escalate
- **Full audit trail** for compliance
- Built with FastAPI + React + PostgreSQL + Docker

## 📊 Impact

| Before | After |
|--------|-------|
| 4-24 hour resolution | < 5 minutes |
| Manual triage | AI classification |
| Context lost in escalation | Structured handoff |
| Same issues, different answers | Consistent best practices |

## 🚀 Demo Flow

1. Employee: "My Outlook isn't receiving new emails"
2. AI classifies → email/outlook category
3. AI retrieves playbook → checks rules, connectivity, storage
4. AI guides: "Let's check if Work Offline mode is enabled..."
5. Issue resolved in 3 minutes ✓

## 🎯 What's Next

- Microsoft 365 API integration for real-time diagnostics
- Proactive issue detection

- Human agent copilot mode

- **Measurable impact** → time saved, tickets reduced
