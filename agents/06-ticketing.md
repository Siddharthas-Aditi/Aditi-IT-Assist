# Agent 06: Ticketing

> **One-liner**: Creates structured support ticket drafts from escalation
> context, ready for user review and submission.

---

## Role

The Ticketing Agent takes the handoff summary from the Escalation Agent and
formats it into a professional support ticket or email draft. It uses an LLM
to generate a human-readable summary, but falls back to templates if the LLM
is unavailable.

---

## Interface

| Direction | Type | Description |
|-----------|------|-------------|
| **Input** | `handoff_summary: HandoffSummary` | From Escalation Agent |
| **Input** | `messages: list[BaseMessage]` | Full conversation |
| **Input** | `issue_category: str` | From Triage |
| **Output** | `ticket_draft: TicketDraft` | Formatted ticket |
| **Output** | `ticket_created: bool` | Always `False` (draft only) |

---

## Algorithm

```python
async def ticketing_node(state: WorkflowState) -> dict:
    """Create a support ticket draft."""
    logger.info("ticketing.start", session_id=state["session_id"])

    summary = state.get("handoff_summary")
    messages = state.get("messages", [])

    # Step 1: Generate conversation summary via LLM
    try:
        conversation_summary = await summarize_conversation(messages)
    except (TimeoutError, ConnectionError):
        conversation_summary = template_summary(messages)

    # Step 2: Build ticket draft
    ticket = TicketDraft(
        title=generate_title(summary),
        description=generate_description(summary, conversation_summary),
        category=map_category_to_ticket_system(summary["issue_category"]),
        priority=summary.get("priority", "P3"),
        steps_attempted=summary.get("steps_attempted", []),
        conversation_summary=conversation_summary,
    )

    # Step 3: Append user message with ticket preview
    user_message = format_ticket_preview(ticket)

    return {
        "ticket_draft": ticket,
        "ticket_created": False,  # Draft only — user must approve
        "messages": [AIMessage(content=user_message)],
        "current_node": "ticketing",
        "audit_trail": [{"event": "ticketing.draft_created", "priority": ticket["priority"]}],
    }
```

## Ticket Format

### Title Generation
```python
def generate_title(summary: HandoffSummary) -> str:
    """Generate ticket title: [Category] Brief description."""
    category_display = summary["issue_category"].replace("/", " - ").title()
    # Truncate description to 60 chars
    description = summary["issue_description"][:60]
    return f"[{category_display}] {description}"
```

## Failure Modes

| Failure | Detection | Recovery | Impact |
|---------|-----------|----------|--------|
| LLM timeout (summary) | `TimeoutError` | Template-based summary | Less polished |
| Missing handoff summary | `summary is None` | Build from available state | Incomplete ticket |
| LLM returns poor summary | Too short/irrelevant | Use template fallback | Less context |
| Category mapping unknown | Category not in map | Use "General" category | May route incorrectly |

## Template Fallback (No LLM)

```python
def template_summary(messages: list[BaseMessage]) -> str:
    """Generate summary without LLM using conversation structure."""
    user_messages = [m.content for m in messages if isinstance(m, HumanMessage)]
    if not user_messages:
        return "No conversation details available."

    first_msg = user_messages[0][:200]
    turn_count = len(user_messages)
    return f"Employee reported: {first_msg}. " \
           f"Conversation lasted {turn_count} turns before escalation."
```

## Boundaries

- ❌ Must NOT send/submit tickets automatically (draft only)
- ❌ Must NOT modify priority without justification
- ❌ Must NOT omit conversation context from ticket
- ❌ Must NOT include raw system internals in ticket
- ✅ Must preserve ALL relevant conversation context
- ✅ Must follow company ticket format template
- ✅ Must include AI confidence in ticket metadata
- ✅ Must present draft to user for review/approval
- ✅ Must include recommended next actions for IT staff
