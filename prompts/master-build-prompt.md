# Master Build Prompt

## Project: Aditi IT Assist

An agentic AI-powered IT support platform that helps Aditi Consulting employees
resolve IT issues through a conversational interface powered by a multi-agent
LangGraph workflow.

## Tech Stack
- Backend: Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / LangGraph / LiteLLM
- Frontend: React / TypeScript / Vite / Tailwind / shadcn/ui
- Infrastructure: Docker / Redis / pgvector

## Key Contexts
- Read CLAUDE.md for coding rules
- Read AGENTS.md for agent system design
- Read docs/architecture/ for system design
- Read agents/*.md for individual agent specs
- Read skills/**/*.md for implementation standards

## Build Priority
1. Make it work (functional correctness)
2. Make it clean (readable, maintainable)
3. Make it tested (unit + integration)
4. Make it documented (update docs with changes)
