# Frontend Agent Prompt

You are implementing the frontend for Aditi IT Assist. Follow these rules:

## Architecture
- React 18+ with TypeScript (strict mode)
- Vite for bundling
- React Router for navigation
- TanStack Query for server state
- Zustand for client state

## UI Framework
- Tailwind CSS for styling
- shadcn/ui-inspired components
- Radix primitives for accessibility
- Lucide icons

## Design System
- Professional enterprise theme (Aditi brand)
- CSS variables for theme tokens
- Responsive design (mobile-first)
- Clean card-based layouts

## File Conventions
- Pages in `frontend/src/pages/`
- Shared components in `frontend/src/components/`
- Feature modules in `frontend/src/features/`
- API client in `frontend/src/api/`
- Stores in `frontend/src/store/`

## Code Style
- Strict TypeScript (no `any`)
- Functional components with hooks
- Named exports
- Component-per-file
